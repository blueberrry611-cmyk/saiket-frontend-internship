## Task Description

Design a product card using HTML and CSS. Include an image, product name, price, and an "Add to Cart" button. Style the card with CSS to ensure proper alignment and add hover effects to the button for a polished look.

## Features

- Product image with a "New" badge
- Product name, short description, and price (₹2,499)
- "Add to Cart" button with a hover effect (colors invert and the button scales up)
- Card lifts with a soft shadow on hover
- Flexbox used for centering the card and aligning the price and button
- Keyboard-friendly focus style on the button
- Respects `prefers-reduced-motion` for users who prefer less animation
- Semantic HTML (`<main>`, `<article>`) and image `alt` text
